# 🎯 AI Mock Interview Platform

An AI-powered web application designed to help students and job seekers prepare for placements and real-world interviews through resume analysis, mock interviews, technical assessments, and performance evaluation.

---

## 📌 Project Overview

The AI Mock Interview Platform provides an intelligent interview preparation system where users can upload resumes, attend AI-based interviews, solve technical assessments, and receive detailed performance feedback.

The system analyzes resumes using Machine Learning, predicts candidate domains and skills, conducts mock interviews, evaluates responses, and generates improvement recommendations.

---

## ✨ Features

✅ User Registration & Login  
✅ Resume Upload and Analysis  
✅ Resume Category Prediction using Machine Learning  
✅ Skill Extraction & Recommendations  
✅ Voice-Based Self Introduction  
✅ Technical Interview Question Generation  
✅ MCQ Assessment Module  
✅ Interview Score Calculation

## ⚙ Installation & Setup

### 1 Clone Repository

```bash
git clone https://github.com/your-username/AI-Mock-Interview-System.git
```

### 2 Move to Project Folder

```bash
cd AI-Mock-Interview-System
```

### 3 Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

---

### 4 Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 5 Run Database Migration

```bash
python manage.py migrate
```

---

### 6 Start Server

```bash
python manage.py runserver
```

Open:

```plaintext
http://127.0.0.1:8000/
```

## 🚀 How It Works

1. User registers and logs in  
2. Upload resume (PDF)  
3. AI extracts and analyzes resume  
4. Resume category is predicted  
5. Skills are identified and recommended  
6. User gives voice introduction  
7. Technical questions are generated  
8. MCQ test is conducted  
9. Final report and score are displayed
